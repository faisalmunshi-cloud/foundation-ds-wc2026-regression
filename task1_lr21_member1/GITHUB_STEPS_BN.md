# GitHub-এ দেওয়ার ধাপ (Member 1)

1. এই ফোল্ডারটা (task1_lr21_member1) repo-র ভেতরে কপি করো।
2. VS Code Terminal-এ repo ফোল্ডারে গিয়ে চালাও:

   git checkout main
   git pull
   git checkout -b member1-lr21-data-eda
   git add task1_lr21_member1
   git commit -m "Add LR 2.1 dataset, EDA, justification table and data dictionary"
   git push -u origin member1-lr21-data-eda

3. GitHub-এ গিয়ে "Compare & pull request" চাপো, একজন Reviewer বেছে নাও, "Create pull request" চাপো।
4. Review হলে Merge করো।
5. Repo -> Projects -> New project -> Board: To do / In progress / Done, কাজগুলো card বানিয়ে assign করো।
